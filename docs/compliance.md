# 合规与数据安全说明

> 一页说清「数据在哪、碰不碰钱、税务怎么算、AI 传了什么」，用于向店主、评审与合作方交代。

---

## 一、数据主权：全部在店主自己的机器上

| 项 | 说明 |
|---|---|
| 账本/熟客/库存/发票 | 存在店主本机 SQLite（`server/data/ai_shopkeeper.db`），**不上传任何服务器** |
| 备份 | `VACUUM INTO` 一致性快照 + 导出 zip；可选择放本机/自己的网盘 |
| AI Key | 由店主自己填（`server/config.local.json`，已被 `.gitignore` 排除） |
| 多店 | **一店一库**物理隔离；成员令牌只放行其所属店铺（越权返回 403） |
| 访问令牌 | 设 `SHOP_ACCESS_TOKEN` 即启用鉴权；局域网/公网部署**建议开启** |

## 二、不碰资金：只解决"收了钱还要手工记账"

- 「收款即入账」生成的是**店主自己收款码**的链接/二维码，**平台不经手资金、不代收代付**；
- 流水同步仅在店主配置了**自己的**微信支付商户号/聚合支付账户后拉取**自己的**账单；
- 无商户资料时可用 `mchid=DEMO` 的演示模式体验，数据带 `[演示]` 标记可一键清空。

## 三、AI 传输边界（重要）

| 场景 | 是否把数据发到外部 |
|---|---|
| 无 API Key | **不发**。记账/账本/算税/保本线全部本地规则完成 |
| 配置了 Key 后使用 AI 功能 | 会把你**选中功能的必要文本**发给所配置的模型服务（如 DeepSeek） |
| 语音记账（小程序） | 微信「同声传译」插件转写（由微信处理）；H5 走**本机 vosk 离线转写** |
| 主动触达推送 | 仅在你配置通道（企业微信机器人/Webhook）后发送；否则写本地收件箱 |

- 所有外部调用**可选、可关闭**，且可整体换成自建/内网模型（`base_url` 自定义）。
- `ai.chat` 有提示词预算护栏（超长告警、超限截断），避免把大段原始数据喂给模型。

## 四、税务计算口径与免责

- 增值税/附加税/个税/企税按**小微企业常用口径**实现（小规模 30 万免征、六税两费减半、个税七级累进等），
  阈值集中在 `server/config.py` 与 `server/tax.py`，可核对、可调整；
- **本项目不提供代账与申报服务**，计算结果为**参考**；正式申报请以主管税务机关口径/专业代账为准；
- 发票台账仅做登记与汇总，不代开发票。

## 五、开源与许可

- 采用**木兰宽松许可证，第 2 版（Mulan PSL v2）**，见 [LICENSE](../LICENSE)；
- 依赖及其许可证见 `server/requirements.lock`；
- 安全审计记录见 [`security-audit-2026-09.md`](security-audit-2026-09.md)。

## 六、我们刻意不做的事（红线）

1. **不默认上传经营数据**；不引入任何"默认联网回传"的行为。
2. **不做资金通道**（不代收、不代付、不沉淀资金）。
3. **不宣称"AI 自我进化已上线"**：进化层默认关闭，需显式开启并通过验证门（见 `deliverables/进化能力研究与优化方案.md`）。
4. **不伪造数据**：仓库内演示数据为程序生成的仿真数据；同业基准为**示例值**并已在接口与文档中标注。
5. **不记录密钥**：任何密钥只落本机 `config.local.json`，不入库、不进日志。
